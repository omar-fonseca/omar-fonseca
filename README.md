# 🚀 Proyectos de software

## ⛽ KORE Station — Plataforma para estaciones de servicio

<div align="center">

<img src="https://skillicons.dev/icons?i=react,nodejs,express,mongodb,jest" alt="React, Node.js, Express, MongoDB y Jest" />

</div>

**Problema:** las estaciones de servicio necesitan integrar operaciones administrativas, acceso de usuarios y control de información en un sistema coherente.

**Solución:** evolución de un proyecto académico hacia una aplicación empresarial modular, con frontend React, backend Express, autenticación JWT y autorización basada en roles.

**Ingeniería:** separación de responsabilidades, contratos HTTP, validaciones, pruebas automatizadas y evolución progresiva de la arquitectura.

**Estado:** en desarrollo. El aislamiento multi-tenant, la persistencia PostgreSQL y varios módulos operativos forman parte de su evolución.

## 🛍️ URB Street — Catálogo web freelance

<div align="center">

<img src="https://skillicons.dev/icons?i=react,ts,vite,tailwind,supabase,cloudflare" alt="React, TypeScript, Vite, Tailwind, Supabase y Cloudflare" />

</div>

**Problema:** un emprendimiento necesitaba mantener actualizado su catálogo comercial sin depender de cambios de programación para cada producto.

**Solución:** catálogo web administrable con ocho categorías, autenticación administrativa, gestión de fotografías y contacto directo por WhatsApp.

**Ingeniería:** integración de Supabase Auth, PostgreSQL, Storage, políticas de acceso, despliegue y control de versiones.

**Estado:** versión funcional documentada. No incluye pagos, carrito ni checkout.
